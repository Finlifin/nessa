# 静态关联类型默认值的具体专化

本阶段补齐用户声明 trait 的静态关联类型默认表达式。现有具体绑定和方法签名
路径已经能够独立归档执行；这里扩展默认值的表达能力，不改变 trait 返回与
存储的 proof carrier。实现状态及验证证据以 implementation-progress 为准。

## 必须保持的语义

- `assoc Item:Type=Self` 在 P/Q 的实现中分别求值为 P/Q。源 `Self` 与显式
  trait 名称区别保存，即使解析阶段两者指向同一个 TypeIndex。
- 默认值可以引用同一声明域的其他关联类型，并嵌套 Optional、Tuple、Function
  或经透明 alias 引用。前向引用不能因声明顺序不同改变结果。
- 先收集该实现的显式覆盖，再求其余默认值。`A=B; B=A` 的默认循环可以由
  `A=String` 的覆盖打断；实际无法求值的循环必须诊断，不能返回 Any。
- 继承关联值来自准确可见的父实现绑定；不能在子实现中重新求父默认值，或
  借用另一个作用域的同名声明。
- 显式 Any 保持 Any。关联引用、Self 以及普通具体类型不能凭索引相等猜测。
- 求值结果必须是可静态执行的具体类型。含 trait 视图或未求值关联叶的结果
  仍须拒绝，直到相应返回、存储或动态绑定协议完成。

## 数据与阶段边界

持久化默认表达式模板，保留 Concrete、Self、关联引用以及结构构造。关联
引用保存声明 owner 和名称；透明 alias 展开后仍保留绑定来源。依赖默认值的
抽象声明使用明确的符号关联类型叶，避免把未知值伪装为 Any 或没有默认值。

解析阶段登记声明与模板；实现安装阶段按精确实现记录求具体绑定，再让现有
方法签名的 associated_paths 替换机制检查实际函数。抽象叶可用于声明及接口
签名，不能进入执行函数签名、全局槽、类型常量、对象字段或指令类型操作数。
普通函数及运行时值不需要新的物理 ABI。

TPOL 的新修订保存模板与符号类型；旧修订读入时没有新模板，不补造声明，也
不改变旧默认值的解释。没有新数据的产物继续按既有修订选择规则写入。外层
NSBC、NSAM 和 builtin ABI 与这项类型元数据扩展独立。

## 验证要求

解析和 TypePool 回归覆盖 Self、别名、前向引用、结构嵌套、覆盖优先、循环、
显式 Any、显式 trait 值拒绝和精确父实现继承。归档往返检查完整模板及具体
绑定，损坏输入覆盖未知 owner/name、非法引用、错误声明叶、重复模板、无法证明的具体绑定
及过深结构，旧修订不得接受新增字段。未实例化的默认引用循环可以保留，
已发布实现的具体绑定仍须完整且不能含符号叶。

端到端测试检查实际结果和反射类型，不能只断言编译成功。删除源码后 CLI
独立执行相同行为；真实 GC 与 continuation 多次恢复检查返回的具体聚合值、
闭包及捕获数据仍可达。执行元数据的恶意符号类型需在运行前拒绝。
