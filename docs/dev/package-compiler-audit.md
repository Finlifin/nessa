# 文件系统包编译管线

Driver 的 `compile_package` 读取受检文件系统输入，`compile_package_sources` 接受拥有
文本的包树，不重新打开诊断路径。完整 manifest 交给真实 PackageResolver，选中的
身份上下文用于根包 TypeID；未找到的依赖明确报错。调用者构造的树先检查逻辑父子
路径、完整词法标识符、同级重名、深度 256、模块总数 65536（含根）、单文件 16 MiB
及源码合计 64 MiB。输入同级顺序不影响编译，模块按逻辑路径排序。

各文件独立解析，保留物理文件位置与原始字节；AST 批量合并保留来源，生成节点
经 `try_add_node` 检查索引与容量并预留存储。该接口要求已有 arena 存储有效，新节点
只能引用已有节点；多子节点范围由接口写入，不采用调用者传入的范围。空模块声明
连接对应文件并保留可见性，非空内联正文、其它同名绑定与重复声明报告冲突。
生成模块保持普通包内可见性和稳定顺序，用户源码不获得 std 的可信标记。

单文件和包输入共用 `compile_ast` 后端，包括 std 加载、名称与类型解析、初始化
规划、NIR、方法身份重映射、最终身份检查和代码生成。NIR 的 `RequiredMain` 在
解析后要求本地根函数且零参数；排除导入、嵌套和非函数 main，拒绝默认或变参
参数，不限制返回类型。既有单文件 `Main` 模式不变。`InitializationOnly` 为 lib/tmp
执行所需初始化并跳过 main；没有初始化工作时允许没有启动入口。

CLI run/check/build 接受目录，归档输出 `package.nsbc`，AST 输出 `package.lisp`。
单文件扩展名行为保留。归档在编译及编码成功后才写出，失败不会创建或覆盖归档。
两个诊断渲染器统一输出 stderr，保留物理路径及 LF/CRLF 的准确行列。AST 的解析
文本仍是叶节点显示依据；无原始范围的生成 Id 使用驻留名称。

独立作者编写 21 个行为与 10 个 CLI 测试，生产依赖精确刷新后第二轮均通过。
覆盖 Unicode/嵌套模块、跨文件类型和初始化回调、完整 TypeID 的路径/版本/命名空间
行为、std 身份、删除源码后归档执行、真实 CLI、准确 3:5 诊断、输入顺序以及
16 MiB 和深度 256 的恰限成功及超限拒绝。首轮 19/2 与 7/3 的原始日志保留：
修复显式 private/缺入口夹具的前提，并通过生产 stderr 修复保留原输出流断言。
全仓旧 CLI 测试中要求重复 stdout 诊断的断言改为 stdout 为空，stderr 错误内容、
拒绝状态与不生成归档断言保留。未注入真实系统 OOM。

本阶段验证图在生产修改和独立测试写入前固定。唯一生产写入和合并者为 root，
测试作者使用隔离副本；共享 Cargo 目录只通过带外部独占锁的脚本使用，自主 clean
不影响源码和证据。初版根及新上下文全仓格式、编译、1830/0/1 测试与严格 Clippy 均通过，
但独立补充边界发现祖先裸名查找绕过 private 模块，C11 未通过，原评分和日志保留。
原图达到六次修复预算后以未通过结束，后续冻结窄修复图，沿用同一验收标准。

解析器现为 FileScope/ModuleDef 记录命名空间边界：private 名称允许同一命名空间
中的函数、块和闭包使用，不能越过子模块边界。普通名称、导入及关联成员共用这一
约束，保留同类型 impl 的私有访问；不可见绑定不会回退到更外层的同名绑定。
新增目录与内联回归，包含根直接访问、闭包捕获和 pub 阳性控制，以及跨模块裸名
和父路径导入拒绝。修复后根和独立新副本的全仓格式、编译、1832/0/1 测试及严格 Clippy 均通过。
原样保留的 7 个独立边界测试全部通过，原 20 次 CLI 操作和新增 18 次私有访问
及阳性控制全部通过。固定标准 11/11 适用项通过；C4 不适用，C1/C2/C7/C8 为
运行记录核对。471 文件基线重放 20 个阶段路径后得到 475 个一致文件。
